## Surface

- **46 grammars** (`vyk --list-languages`), **10 token kinds**
  (stable — an ADR and a CHANGELOG entry to change), 12-byte `Token`
  (ADR 0002).
- **Public API:** the streaming push primitive
  (`tokenize_stream_new` / `_feed` / `_drain` / `_finish` / `_free`)
  and pull adapter, `has_grammar`, `list_languages_into`,
  `bootstrap_grammars`, detection (`detect_language`,
  `detect_language_from_content`, `detect_language_combined`), and
  `grammar_load` for a consumer's own `.cyml`. The header of
  `src/tokenize.cyr` is the authoritative list.
- **Grammar format:** CYML. Rule types line (with `start_after`,
  ADR 0022), pair, words, compose, compose_fenced (with `end_indent`,
  and tags resolved by name, extension or interpreter — ADR 0016),
  compose_region (`end_before` optional: run to EOF, ADR 0019),
  heredoc (ADR 0023); line rules may also require or forbid a next
  byte (`followed_by` / `not_followed_by`, ADR 0027). `[defaults]`
  includes `number_float`, `number_separator`, `number_datetime`,
  `number_tuple_index` (ADR 0026), `string_prefixes` / `raw_string_prefixes` and
  `ident_lead` (ADR 0027). `extensions` / `filenames` / `shebangs`
  declare detection (ADR 0025).
- **`vyk`:** NDJSON or `--theme` ANSI output, `--export-theme`, `-` for
  stdin, exit codes 0–4, input capped at 1 MiB (`VYK_SRC_CAP`); a
  write failure exits 3. `vyk --help` and `docs/man/vyk.1` are current.

## Contracts as they stand

- **Coverage:** tokens tile the input exactly, for every grammar and
  every input.
- **Chunk invariance:** streaming output equals a single feed at every
  split offset for all 49 corpus inputs — the compose grammars
  (markdown, html, vue, svelte, cyml) included since 2.8.0 — gated by
  `fuzz/chunk_invariance.fcyr` (8 chunk sizes, two-feed splits every
  37 bytes; 49 shapes at every split offset and in 1-, 2- and 3-byte
  feeds). The drain commits only what the
  scanner reports settled: heredoc and compose holds, groups that
  commit whole, the marker window, watches that wait on new bytes
  (ADR 0028).
- **Streaming bounds:** `VYK_STREAM_CAP` 16 MiB live buffer;
  `VYK_COMPOSE_HOLD_MAX` 8 MiB for a still-open compose region and
  `VYK_HEREDOC_HOLD_MAX` 1 MiB for a still-open heredoc group, measured
  from its line's first opener. Past a bound, fed in chunks, the held
  bytes commit as that drain's scan read them, which may differ from a
  single feed from there on; 4 GiB per stream (ADR 0021). An unresolved
  compose region gives no tokens until it closes or the stream
  finishes.
- **Detection:** compiled in `src/detect.cyr`, declared by the grammars,
  checked both ways (ADR 0025). A `filenames` entry matches an anchored
  ending (`ci/app.Dockerfile`) or `name.` + a suffix that starts with a
  letter and is not a compression, patch or tool suffix
  (`Makefile.in`, not `Dockerfile.5.gz`). The content sniff is a shebang,
  `<?xml`, `<!DOCTYPE html>`, and the `.s` / `.S` asm vote (ADR 0015).

## Known limits (coverage holds)

Each names the 2.9.x arc release that takes it on ([roadmap](./roadmap.md)).

- **Numbers:** a leading- or trailing-dot float (`.5`, `1.`), hex
  floats and every suffix (`1.5f`, `2j`, `1u32`) split (ADR 0026) —
  2.9.7.
- **String prefixes** are declared per grammar and identifier-shaped
  (ADR 0027): C#'s `@"…"` / `$"…"` need a non-identifier prefix
  (2.9.6), and Julia string macros other than Base's `raw` / `r` / `b`
  / `v` are not declared. Until then they are prefix + string.
- **Variable-length delimiters beyond shell heredocs** — Rust
  `r#"…"#`, C++ `R"d(…)d"`, Lua `[==[ … ]==]`, Swift `#"…"#`, and Ruby
  and PHP heredocs (neither grammar has a heredoc rule) — 2.9.5, by
  extending the heredoc rule (ADR 0023). Not error-free: a `r#"…"#`
  whose body holds quotes and backslashes surfaces `error` tokens after
  the first inner quote (2 of 5,166 sampled real files at the 2.9.x
  audit).
- **Nested block comments** close at the first `*/` (rust, swift),
  `-}` (haskell), `*)` (ocaml) or `=#` (julia): a pair rule does not
  count depth, so the rest of the outer comment tokenizes as code. Not
  scheduled.
- **Markdown fences:** `~~~` and four-or-more-backtick fences and
  indented code blocks are not recognised (ADR 0016); a closer may be
  indented by any run of spaces, tabs and `>`, so a column-0 fence whose
  body holds an indented ```` ``` ```` line closes there.
- **Streaming latency inside compose regions:** a long, still-open
  `<style>` / fence / cyml body is held whole until it closes (ADR 0028;
  a resumable region is 2.9.10).
- **No incremental retokenization:** an edit means tokenizing the
  buffer again (or streaming it); an edit API is 2.9.11.
- **Out of scope:** Python INDENT / DEDENT and anything structural —
  vyakarana yields spans.

  worked around here.
