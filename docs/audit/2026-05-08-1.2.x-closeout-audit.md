## Methodology

For each scanner code change since 2026-04-23, walked every
`load8` / `store8` / `alloc` and confirmed bounds against
`src_len`. Re-ran the 2026-04-23 audit's known-CVE checklist
against the new code shape.

## Findings

### Bounds checks on new scanner code

**`_ds_scan_ident` unicode_ident branch** (`src/grammars/default_scanner.cyr`):

```cyrius
while (j < src_len) {           # outer bound ✓
    var b = load8(src + j);     # safe: j < src_len
    var ok = char_class_match(cont_tbl, b);
    if ((ok == 0) && (unicode_on == 1) && (b >= 128)) { ok = 1; }
    if (ok == 0) { return j - i; }
    j = j + 1;
}
return src_len - i;
```

Single bounded byte read per iteration, no allocation, no
pointer arithmetic on derived offsets. Clean.

**`_ds_try_char_literal`** (`src/grammars/default_scanner.cyr`):

The function's first non-trivial check is
`if (i + 2 >= src_len) { return 0; }`, which guarantees `i+2 <
src_len` thereafter. Each subsequent multi-byte path adds its
own range check (`if (i + 3 < src_len)`, `if (i + 5 < src_len)`)
before reading. Reviewed all four shapes (`'C'`, `'\C'`,
`'\xHH'`, UTF-8 bodies):

- 3-byte `'C'`: needs `i+2 < src_len` ✓ (already guaranteed).
- 4-byte `'\C'`: needs `i+3 < src_len`, explicit guard present.
- 6-byte `'\xHH'`: needs `i+5 < src_len`, explicit guard
  present (and `i+5` is checked before `load8(src + i + 5)`).
- UTF-8 bodies: each leading-byte range branch has its own
  `i + N < src_len` guard.

No path can read past `src + src_len - 1`. Clean.

1.2.3 added 1; the `c.cyml` / `markdown.cyml` updates from 1.1.0
were already covered by the 2026-04-23 audit). All are pure

ABI.

### Dead-code cleanup (1.2.4)

`registry_get`, `registry_count`, `grammar_count`, `_g_cstr_copy`
removed. `kind_is_valid` flagged dead by the binary build but
intentionally retained — it's exported via `[lib] modules` for
downstream validators (test suite uses 5 assertions on it). No
behavioural change, no API removal that downstream consumers
were relying on (the removed functions were never documented as
public surface).
