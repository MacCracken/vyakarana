## Surfaces reviewed

### `src/lsp.cyr` (1.11.0 — LSP semantic-tokens bridge)

Pure functions, no allocation, no buffer access. Two entries:

- `lsp_kind_from_token_type(name)` — string compare against a
  closed set of literals; returns a `TK_*` integer.
- `lsp_kind_from_standard_index(idx)` — integer dispatch with
  default-fallback to `TK_IDENT`.

**No findings.** No memory access, no I/O, no allocation.

### Grammar composition (1.11.1)

`_ds_try_compose_rules` in `src/grammars/default_scanner.cyr`
recursively invokes `tokenize_with_grammar` on the body bytes.
Recursion depth is bounded by grammar nesting in the source,
which is bounded by source length. No memo-table growth, no
backreferences, no quantifier blow-up. Verified by
`tests/vyakarana.tcyr` 1.12.0 stress probe (6 adjacent
compose blocks) and `fuzz/tokenize.fcyr` adversarial input
`<style>{<script><<<<</style>` — no crash, coverage holds.

The recursive call uses the parent's tokenbuf with offset
shifting — the inner grammar receives `body_src` and
`body_len`, emits tokens with starts in [0, body_len), and the
parent rewrites starts to `marker_start + body_offset + s`
before pushing. No buffer aliasing issue: the inner grammar
reads from the same `src` buffer, and shift math is bounded
by `marker_start + body_offset + body_len ≤ src_len` (the
caller computes `body_len` from a literal end-marker match
in [marker_start, src_len], so this holds by construction).

**No findings.**

### `src/theme_export.cyr` (1.11.1)

Read-only walk over a fixed kind table, emits to stdout via
`print`. No reads from caller-supplied bytes. Output format
is line-oriented JSON; no escaping bug surface because the
scope strings and hex values are compile-time literals.

**No findings.**

### `src/grammar_blobs.cyr` + `src/grammar.cyr` blob path
(1.11.1)

`grammar_load(path)` flow:

1. Lookup path in `_grammar_blob_data` (linear `streq` over
   38 known paths).
2. If blob found: `strlen(blob)` to get length; `memcpy`-style
   loop into `alloc(GRAMMAR_FILE_CAP)` buffer; NUL-terminate;
   call `_gp_parse(buf, n)`.
3. Else: original `file_read_all` path.

Bounds review:
- `strlen(blob)` returns ≤ 32KB for any current grammar
  (largest is `llvm_ir.cyml` at ~6.7KB; `GRAMMAR_FILE_CAP` is
  32KB).
- The copy loop runs `i < bn` with `bn = strlen(blob)`. Source
  is a Cyrius string literal in read-only segment. Destination
  is `alloc(GRAMMAR_FILE_CAP)` — a 32KB buffer. As long as
  blob length stays under 32KB, the copy is safe.
- `scripts/embed-grammars.sh` rejects any control byte
  (`\x00`-`\x08`, `\x0b`, `\x0c`, `\x0e`-`\x1f`) in the
  source `.cyml`. No NUL bytes can sneak into the literal,
  so `strlen` can't undercount the content.

**FINDING-007 (LOW, fixed in-pass):** `grammar_load` did not
enforce `bn < GRAMMAR_FILE_CAP - 1` before the copy loop. If a
future grammar grew past 32KB, the copy would overflow the
alloc'd buffer. Today the largest grammar is 6.7KB so this was
purely defense-in-depth.

*Fix applied:* one-line clamp
`if (bn > GRAMMAR_FILE_CAP - 1) { bn = GRAMMAR_FILE_CAP - 1; }`
before the copy in `src/grammar.cyr`. Cost: one extra branch in
cold-path init.

### `src/detect.cyr` (1.11.2)

Three entries: path string suffix matching, content byte
sniffing, combined dispatch. All bounded:

- `detect_language(path)`: pure cstr suffix match. Each
  comparison is `n >= K` guarded; no out-of-bounds read.
- `_detect_skip_bom`: 3-byte prefix peek with explicit
  `src_len < 3` guard.
- `_detect_starts_with`: `i + nl > src_len` guard before
  every memeq.
- `_detect_index_of`: `start + nl > src_len` guard; loop
  upper bound `i <= limit = src_len - nl` so the final
  `memeq(src + i, …, nl)` reads at most `src_len - 1`.
- `_detect_shebang`: walks `[2, line_end)` where `line_end ≤
  src_len`. Word-end search bounded by same.
- `_detect_asm_flavor`: scan capped at `min(src_len, 4096)`.
  Each `_detect_index_of` call uses the capped scan length.

Verified: `fuzz/detect.fcyr` exercises 10/64/256-byte random
buffers, BOM-only inputs, NUL-truncated shebangs, and
empty content. All return either 0 or a registered grammar
name; no crash, no out-of-range strlen.

**No findings.**

## Fuzz / stress coverage (1.12.0)

- `fuzz/tokenize.fcyr` — empty, 1-byte sweep ×3 grammars,
  pseudorandom buffers ×3 sizes ×6 grammars ×16 iters,
  adversarial inputs (compose nesting, comment soup, escape
  jumble). All hold the 4 invariants (non-null tokenbuf,
  positive lens, non-decreasing starts, coverage = strlen).
- `fuzz/detect.fcyr` — pathological paths (empty, slash-only,
  long random), random byte buffers ×3 sizes ×16 iters,
  BOM-only / shebang-NUL / truncated-PI inputs, combined
  dispatch with `.s` × random content. All return 0 or a
  registered grammar name.
- `fuzz/grammar_load.fcyr` — 8 known blob round-trips,
  printable-random CYML through `_gp_parse` ×3 sizes ×8 iters,
  pathological CYML (empty headers, runaway open-quote). No
  crashes; null-or-valid handle returned.
- `tests/vyakarana.tcyr` 1.12.0 stress probes — runaway
  `/* */` and `"…`, block-comment soup, broken UTF-8
  mid-ident, unclosed `<style>` compose, 6× adjacent
  compose blocks, 4KB ident run. Coverage invariant holds
  in every case.
