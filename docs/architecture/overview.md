# Architecture overview

System-level module map and the contracts vyakarana ships. This
file is durable — it changes when the architecture changes, not
on every release. Live status lives in
[`../development/state.md`](../development/state.md).

---

## Mission

Source-code tokenizer for the AGNOS stack. Take source bytes →
yield `(kind, start, len)` spans into the caller's buffer, fast
and without surprises. Consumers (owl, cyim, vidya)
decide what to do with the tokens; vyakarana never renders, never
parses past the lexical layer.

The hand-coded `src/grammars/shell.cyr` sits parallel to the
default scanner as a regression oracle — `vyk --handcoded` and
`scripts/smoke.sh`'s diff check exercise it so the data-driven
path can never silently drift away from the M1 reference.

## File-by-file

- **`grammars/*.cyml`** — 46 grammar files (see "Bundled
  grammars" below). Each is a `[grammar]` header (name, plus the
  `extensions` / `filenames` / `shebangs` that detection routes
  on — [ADR 0025](../adr/0025-detection-declared-by-grammars.md)),
  a `[defaults]` table for built-in scanner stages, and `[[rules]]`
  entries for line / pair / words / compose / compose_fenced /
  compose_region / heredoc. `grammars/json.cyml` is the plainest
  example, `grammars/shell.cyml` the most specialised.
- **`src/grammar.cyr`** — `Grammar` record and rule sub-records
  (layouts in the file header; the record is 288 bytes at 2.9.7),
  char-class tables (256-byte lookup), CYML parser (minimal TOML
  dialect; a malformed grammar is rejected, not loaded), and the
  in-memory registry.
- **`src/grammar_blobs.cyr`** — generated by
  `scripts/embed-grammars.sh` and gitignored: every
  `grammars/*.cyml`, compacted, as a Cyrius string literal, which
  `grammar_load` reads first ([ADR 0014](../adr/0014-embedded-grammar-blobs.md),
  [ADR 0029](../adr/0029-compacted-blobs-posix-generator-size-budget.md)).
- **`src/grammars/default_scanner.cyr`** — `tokenize_with_grammar`,
  the 11-step pipeline that every data-driven grammar runs through.
  Pipeline order is normative; see [architecture note
  002](002-scanner-pipeline-priority.md).
- **`src/grammars/shell.cyr`** — hand-coded M1 tokenizer, retained
  as a regression oracle. Wired into `vyk --handcoded` and the
  smoke diff check.
- **`src/tokenize.cyr`** — public streaming primitive (2.0+).
  `tokenize_stream_new(lang)` allocates a stream; `_feed(s,
  chunk, n)` buffers bytes; `_drain(s, tb)` / `_finish(s, tb)`
  emit tokens; `_free(s)` releases; the pull adapter (`_next` /
  `_kind` / `_start` / `_len`, `_discard_consumed`) iterates the
  same stream. Loads bundled grammars
  lazily on first `_new` / `has_grammar` call.
  `bootstrap_grammars()` is the explicit-load hook. See
  [ADR 0017](../adr/0017-streaming-api.md) and
  [ADR 0028](../adr/0028-streaming-holds-watches-groups.md). The 1.x
  `tokenize_source(src, lang)` synchronous entry was removed. The
  file's header is the authoritative list of public symbols.
- **`src/detect.cyr`** — `detect_language` (path),
  `detect_language_from_content` (shebang / signature sniff) and
  `detect_language_combined`, which the CLI uses
  ([ADR 0015](../adr/0015-content-based-detection.md),
  [ADR 0025](../adr/0025-detection-declared-by-grammars.md)).
- **`src/lsp.cyr`** — LSP semantic-token type → `TK_*` mapping
  ([ADR 0012](../adr/0012-lsp-semantic-tokens-bridge.md)).
- **`src/token.cyr`** — palette, `Token` layout, `tokenbuf` (see
  [ADR 0002](../adr/0002-token-storage-layout.md)). Accessors
  `tokenbuf_count/kind/start/len` are the consumer contract.
- **`src/main.cyr`** — `vyk` CLI. `tokenize_buf`, `emit_ndjson`,
  `emit_themed`, and the `--handcoded` flag used by the regression
  diff. CLI-only helpers, not in the bundle: `src/theme.cyr`
  (bundled themes), `src/theme_export.cyr` (`--export-theme`),
  `src/out.cyr` (checked, buffered stdout).
- **`src/version_str.cyr`** — auto-generated `VYK_VERSION`. Single
  source of truth for `vyk --version`; regenerated by
  `scripts/version-bump.sh`.
- **`tests/corpus/*`** — corpus files (vidya snapshots +
  ADR-0006 stand-ins, at least one per bundled grammar). See
  `tests/corpus/README.md`.
- **`tests/vyakarana.tcyr`** — assertion suite covering palette,
  tokenbuf, hand-coded known offsets, grammar loader, char-class,
  cross-tokenizer equality, and per-grammar probes.
- **`scripts/smoke.sh`** — M0 flag probes + M1 shell round-trip +
  M2 hand-vs-data-driven diff + M3 corpus round-trip loop (one
  line per `lang:corpus` pair), plus CLI and detection probes and
  `scripts/check-detect.sh`.
- **`fuzz/*.fcyr`** — `cyrius fuzz` harnesses; `chunk_invariance`
  holds streaming output equal to a single feed over every corpus
  file.
- **`dist/vyakarana.cyr`** — concatenated single-file distribution
  driven by `[lib] modules` in `cyrius.cyml`, with its
  `dist/vyakarana.deps` stdlib sidecar. What downstream
  consumers actually pull. See
  [ADR 0014](../adr/0014-embedded-grammar-blobs.md) and
  [`../development/distribution.md`](../development/distribution.md).

## Frozen public contracts

These are stable across the 2.x line (2.0.0's one break was item
3's entry point). Breaking any of them is an
ADR-level decision that requires a major version bump and the
user's explicit ACK.

1. **Ten token kinds in `src/token.cyr`.** The palette is a stable
   contract. Adding a new kind requires a design review and a
   CHANGELOG entry.
2. **Token layout.** `(kind: u8, start: u32, len: u32)` — 12 bytes,
   no pointers. See [ADR 0002](../adr/0002-token-storage-layout.md).
3. **Public entry shape (2.0+).** The streaming primitive —
   `tokenize_stream_new` / `_feed` / `_drain` / `_finish` /
   `_free` — is the consumer contract, with the pull adapter and
   registry calls listed in `src/tokenize.cyr`'s header. Names and
   arg order stable across the 2.x line. The 1.x `tokenize_source`
   is gone (ADR 0017). Implementation internals (per-token-resume,
   rolling buffer) can change without breaking consumers.
4. **`vyk` CLI surface.** `--version`, `--help`, `--list-kinds`,
   `--list-languages` are covered by the smoke test. Additions
   are fine; renames/removals are breaking.

## Invariants that carry forward

The non-negotiables that any future ADR must work *with*, not
around.

- **Coverage invariant.** Every input byte produces exactly one
  output token, with `error` kinds emitted explicitly when no
  other rule matches. See [architecture note
  001](001-coverage-invariant.md). This is the project's
  correctness contract.
- **Zero-copy spans.** Tokens reference into the caller's bytes as
  `(kind, start, len)` — offsets, never pointers or copied text.
  `tokenbuf` grows by doubling, not per-token (see
  [ADR 0002](../adr/0002-token-storage-layout.md)). The stream
  does copy each fed chunk into its own rolling buffer to scan it
  ([ADR 0017](../adr/0017-streaming-api.md)); no token points
  there.
- **No regex rules.** Explicitly out of the rule set (design-spec
  §5, [ADR 0005](../adr/0005-m2-rule-type-scope.md)). If a
  language needs lookahead, propose a new rule type in a new ADR
  — don't reach for regex.
- **Data-driven by default.** New grammars are new `.cyml` files.
  If a grammar needs behaviour the default scanner doesn't
  support, extend the scanner (and record via an ADR); don't add
  per-language Cyrius paths.
- **Regression oracle retained.** `src/grammars/shell.cyr`
  (hand-coded) is on disk so smoke.sh's diff check works. Delete
  in a future hardening pass only when M3 grammars have stayed
  green long enough to trust the data-driven path without the
  oracle.
