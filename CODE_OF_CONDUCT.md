# Code of Conduct

vyakarana is part of the
[AGNOS library](https://github.com/MacCracken/agnosticos) and
follows the AGNOS umbrella code of conduct. The short version:

- **Be excellent to each other.** Disagree with ideas, not with
  people.
- **Assume good faith.** Most disagreements come from missing
  context, not malice. Ask before escalating.
- **Stay focused.** This project is about a fast, predictable
  source-code tokenizer. Conversations should serve that goal.
- **No harassment.** Personal attacks, slurs, sexualized language
  or imagery, or sustained disruption of discussions aren't
  tolerated.

Reports of unacceptable behavior go to **cyriusmaccken@gmail.com**.
Reporters won't be retaliated against.

The maintainer reserves the right to remove comments, close
discussions, or ban contributors whose behavior conflicts with
this Code.
